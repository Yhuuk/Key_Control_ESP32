# 文档说明
| 文件/目录                  | 是否上传 | 说明                    |
| ---------------------- | ---: | --------------------- |
| `src/main.cpp`         |   上传 | 你的主程序源码，必须上传          |
| `include/`             |   上传 | 头文件目录，如果你有 `.h` 文件要上传 |
| `lib/`                 |   上传 | 如果里面是你自己写的库，要上传       |
| `test/`                |   上传 | 如果你写了测试代码，可以上传        |
| `platformio.ini`       |   上传 | PlatformIO 核心配置，必须上传  |
| `.gitignore`           |   上传 | 告诉 Git 忽略哪些文件         |
| `README` / `README.md` |   上传 | 项目说明，可上传              |
